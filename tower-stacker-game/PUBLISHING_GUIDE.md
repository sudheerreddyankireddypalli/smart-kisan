## 2. Step 1: Free Global Hosting on GitHub Pages (₹0 Cost)

Web game portals require a playable link or a zip file. You can host this game online for free in 2 minutes:

1. Create a free account at [github.com](https://github.com) (if you haven't already).
2. Create a new public repository (e.g., `sky-high-stack`).
3. Upload the 4 files from `tower-stacker-game`:
   - `index.html`
   - `style.css`
   - `game.js`
   - `ads.js`
4. Go to **Repository Settings** -> **Pages** (under "Code and automation").
5. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
6. In ~60 seconds, your game is live globally at:
   `https://<your-username>.github.io/sky-high-stack/`

## 4. Monetization Flow Built Into This Game

1. **High-Converting Rewarded Ad ("Revive Tower")**:
   - Hyper-casual players hate losing progress after a 40-block run.
   - Offering a 1-time revive per session yields the highest ad completion rate in mobile and web games (~70-85% opt-in).
2. **2x Coin Multiplier**:
   - Incentivizes players to watch an ad before quitting to unlock the premium skins (Pastel, Imperial Gold, Emerald).
3. **Midgame Interstitial Ads**:
   - Automatically scheduled after every few game-over cycles to monetize non-rewarded sessions without annoying the player.
